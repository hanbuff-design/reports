什么是非侵入式脑机接口

Non-invasive BCI
脑机接口（BCI）是在大脑与外部设备之间建立直接信息通路的系统；按信号采集方式分为侵入式 / 半侵入式 / 非侵入式。本报告的非侵入式（Non-invasive）路线，指通过脑电图（EEG）、功能性近红外（fNIRS）等体外传感器，无创捕捉脑活动信号，无需手术——安全性高、易普及，是当前脑机接口产业化的核心主流方向。

主流信号载体是头皮 EEG（时间分辨率高、便携、成本低），配套干 / 湿 / 半干 / 水凝胶电极与神经信号放大 / 模数转换芯片；下游覆盖医疗康复（卒中 / 脊髓损伤 / 癫痫 / 抑郁）、消费电子（睡眠 / 专注力 / 游戏）、科研教学三大场景。

投资视角的核心矛盾：非侵入式 BCI 听着性感，但 A 股并无"脑机接口"独立板块，相关标的散落在脑科学、医疗器械、智能穿戴、医疗服务等大概念里；真正能拿出出货量、单价、毛利率的玩家多在未上市龙头（强脑科技 / 博睿康），A 股多数公司只是叙事受益方而非业绩受益方。

上中下游分层详解

Benefit Logic & Certainty
上游 · 脑电采集硬件与信号链

代表公司

汉威科技（柔性微纳传感器 / 苏州能斯达超柔性脑电传感器，中标工信部"脑机接口关键器件"专项）；神经信号模拟前端芯片（ADI ADS1299 系国产替代）；乐心医疗 / 九安医疗 / 三诺生物（可穿戴头戴硬件底座）。

受益逻辑

非侵入式 BCI 的"卖铲人"——电极、柔性传感、信号放大 / ADC 芯片是所有脑电采集设备的底层刚需。无论中游谁做出脑机系统，都要向上游采购核心器件，订单可见、国产替代弹性足。

确定性

★★★★★ 最高。卖铲子逻辑，不依赖单一应用爆发；汉威传感器已获国家级专项背书。

真受益 · 强 确定性：高
中游 · BCI 系统与算法平台

代表公司

脑电采集设备：博睿康（未上市，2025 脑电图机国内第一）、翔宇医疗、伟思医疗；解码算法：科大讯飞（汉语言实时解码 95%）、岩山科技（岩思类脑数字孪生脑）、强脑科技（BrainCo）；神经反馈康复：创新医疗（控股博灵脑机 68.36%）。

受益逻辑

掌握整机 + 算法，可通过医疗器械销售、康复服务、消费级订阅变现。博睿康脑电图机已规模化（2025 销量 488 套），讯飞 / 岩山算法在医疗与消费两端落地。

确定性

★★★☆ 分化且多早期。头部有真实出货，但多数 A 股公司"脑机产品尚未规模化销售、营收占比小"（翔宇 / 伟思公告原话），仍处市场培育期。

真受益（少数）· 多数早期 确定性：中
下游 · 应用场景

代表公司

医疗康复：三博脑科（神经专科临床，但明确"不做产品"）；消费电子：强脑科技安睡仪 / 头环、游戏脑控；科研教学：高校院所采购脑电设备。

受益逻辑

脑机在康复、睡眠、专注力、科研中确有刚需。但下游应用方多为"使用设备的人"，自身不生产核心部件——三博脑科是医疗服务商，强脑科技虽做产品但属未上市消费级，A 股纯下游标的受益传导极弱。

确定性

★★☆ 最易蹭概念。三博脑科（不做产品）、南京熊猫（课题完成尚无收入）等"概念股"与脑机业绩基本无直接关联。

真伪混杂 · 多蹭概念 确定性：低~中

4.4技术路线对比· 电极路线 + 信号模态

技术路线原理 / 关键特征核心指标适用场景代表玩家
湿电极（凝胶 / Ag-AgCl）导电凝胶建立离表皮离子通道，金标准阻抗 <10 kΩ、信噪比高、可靠；但准备繁琐、不适临床 / 科研 EEG 主流博睿康 / 翔宇 / 伟思
干电极（金属针 / 导电聚合物）无凝胶，快戴、自戴、清洁阻抗数百 kΩ、运动伪迹敏感、信号较差消费级头环 / 快速筛查强脑 / 岩山（部分）
半干电极（控释电解质）缓慢释放盐水，折中方案阻抗 ~44 kΩ、稳定、可较长时佩戴科研 + 准消费过渡高校 / 初创
水凝胶电极双层水凝胶，可贴附、抗运动伪迹阻抗≈湿电极、可连续 12h、生物相容好长时监测 / 消费健康强脑（已应用）
EEG 信号（主流模态）头皮电位，时间分辨率高毫秒级时间分辨率、空间分辨率低通用非侵入式 BCI全线玩家
fNIRS（近红外）血液动力学响应，空间分辨率高空间好、时间亚秒级、无创认知 / 情绪 / 语言研究麦澜德（双模态）
fMRI（功能核磁）血氧信号，空间分辨率极高空间优、设备庞大、单台数十万美元科研，难普及院所

核心结论：医疗 / 科研主流量产路线仍是湿电极 EEG（博睿康凭此拿下国内第一）；消费级走向干 / 半干 / 水凝胶以换取便捷性，代价是信号质量。多模态融合（EEG + fNIRS）是提升解码精度的明确方向。技术难点在信号降噪、抗运动伪迹、个体自适应解码——算法与电极材料是壁垒所在。
来源口径：技术对比综合自 SCI 论文（ScienceDirect / Nature 子刊）、科普与行业资料（学术 / 行业口径）。

来源口径：各公司在研与产品进展来自 NeoData（年报 / 公告）+ 公开报道 / 公司 IR（行业口径）。

真受益 vs 伪受益

Genuine vs Hype

✅ 真受益（业务 / 出货可验证）

有真实产品、出货或订单，非侵入式 BCI 是确定性增量而非单纯叙事。

  • 上游卖铲子：汉威科技（柔性脑电传感器中标工信部专项）——无论中游谁赢都先受益，确定性最高。
  • 中游真有产品：博睿康（未上市，2025 脑电图机国内第一、销量 488 套、毛利 78%）；翔宇医疗 / 伟思医疗（脑电机 / 经颅磁已获证产生收入）；创新医疗（控股博灵脑机，偏瘫康复双产品）。
  • 算法真落地：科大讯飞（汉语言解码 95%）、岩山科技（岩思类脑数字孪生脑 + LumiSleep 预售）。
  • 消费级放量龙头：强脑科技（安睡仪 4 万+ 销量、仿生手、与喜临门床垫）。

⚠️ 伪受益 / 蹭概念（叙事 > 业绩）

与 BCI 关联弱或无实质产品 / 收入，主要靠"宣布布局 / 课题 / 板块标签"贴金。

  • 三博脑科：明确公告"我们不做产品，做手术的"，神经调控收入占比极小、对业绩基本无影响——典型伪标的。
  • 南京熊猫：参与省级课题、脑控终端开发完成，但"尚未产生脑机接口相关销售收入"。
  • 板块成分噪声：寒武纪（算力）、物产中大都非 BCI 玩家，只是脑科学板块成分股，强行关联。
  • 可穿戴邻近：乐心 / 九安 / 三诺是健康硬件，非 BCI 核心；世纪华通（游戏）、佳禾智能（耳机）仅边缘相关。

🔍 三步甄别"真伪受益"清单（含量价利验证）

  1. 看收入来源：有没有因 BCI 产生的真实订单 / 板块收入？纯"布局中 / 研发中 / 课题中"≠ 受益。能拿出货量、单价、毛利率的公司可信度远高于只会"宣布布局"的——博睿康（488 套 / 15.91 万 / 77.9%）即铁证。
  2. 看在链条的位置：越靠上游（电极 / 芯片）越确定；中游看是否真有注册证与出货；下游应用方要确认是否卡住"不可替代"环节，而非只是普通使用方。
  3. 看估值与兑现节奏：岩山科技 PE 464、三博脑科 PE 184、南京熊猫 PE 269 估值畸高却无脑机收入；多家公司公告"尚未规模化、营收占比小"，已透支预期，回调时最受伤。
7

客观判断

Objective View · 非投资建议

非侵入式 BCI 是"长坡厚雪"的确定性赛道，但 A 股受益高度集中且多在早期

在政策（工信部等七部委《关于推动脑机接口产业创新发展的实施意见》、"十五五"前瞻布局）、资本（2025 年脑机融资 26 起 / 17.78 亿元，同比大增）与临床需求（3 亿失眠人群、卒中康复刚需）三重驱动下，非侵入式 BCI 产业趋势确定、增速约 20%。但落到股票上，受益分层且衰减明显：上游最先最确定兑现，中游分化极大，下游多数为蹭概念。

1最受益的是上游采集硬件 / 信号链。电极、柔性传感、模拟前端芯片是刚需卖铲子，汉威科技已获工信部专项背书，确定性最高，不依赖单一应用爆发。
2真实放量主力在未上市龙头。博睿康（脑电图机国内第一）、强脑科技（估值 92 亿独角兽）已拿出出货量 / 收入；A 股多数公司仍"产品未规模化、营收占比小"，是早期而非业绩受益。
3中游认"有注册证 + 出货"而非"有概念"。翔宇 / 伟思获证产生收入、讯飞 / 岩山算法落地，可信；单纯"脑机布局"PR 股需警惕。
4伪标的重灾区是"路线错配 / 做服务不做产品"。三博脑科（不做产品）、南京熊猫（无收入）最该点破；板块里的寒武纪 / 物产中大纯属成分噪声。
5警惕高估值与伪标的。岩山 PE 464、三博 PE 184、南京熊猫 PE 269 却无脑机收入，多家公告"尚未规模化"，已隐含大量预期，回调风险大。
6单日涨跌不代表产业确定性。当日世纪华通 +8.23%（游戏驱动）、创新医疗 -10.02%（高位回落），更多反映短线情绪；判断应看注册证、出货量、毛利率与兑现节奏，而非一日 K 线。
